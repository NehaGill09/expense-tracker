# Expense Tracker

A Python command-line expense tracker.

## Features
- Add expenses with amount, category, description, and date
- Monthly totals
- Totals by category
- List expenses
- CSV export
- Local CSV storage

## Requirements
Python 3.10+. The application uses only the standard library. Install pytest for tests.

## Run
python expense_tracker.py

## Test
python -m pip install -r requirements.txt
python -m pytest

Personal data in expenses.csv is ignored by Git.
